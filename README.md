Vehicle obby in a jungle / Aztec temple
- Starts in a dense jungle over a canyon river with a zipline to a temple
- Optimised for 70fps on Quest2
- Zipline over the river, escape Indiana jones style boulder chase, crushing walls and jumps over lava
- Meant to be an easier version of https://github.com/owen-chair/BuggyPyramid
- Also includes live server for leaderboards

- Trucks from https://github.com/owen-chair/OptimisedFork-SaccFlightAndVehicles
